# 📈 Stock Trading Platform

A **console-based Stock Trading Platform** developed using **Java** and **Object-Oriented Programming (OOP)** as part of the **CodeAlpha Java Programming Internship**.

This application simulates a basic stock market where users can buy and sell stocks, manage their portfolio, calculate profit/loss, and save portfolio data using file handling.

---

# 📖 Project Overview

The Stock Trading Platform is designed to simulate real-world stock trading. It allows users to purchase and sell stocks, view market prices, manage their investment portfolio, and calculate their current assets.

The project is built using Java and follows Object-Oriented Programming principles with a clean class-based architecture.

# ▶️ How to Run

1. Clone or download this repository.
2. Open the project in Eclipse IDE.
3. Run `StockTradingPlatform.java`.
4. Choose options from the menu.
5. Buy, sell and manage your stock portfolio.
